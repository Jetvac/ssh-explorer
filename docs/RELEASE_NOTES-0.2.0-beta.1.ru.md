# SSH Explorer 0.2.0-beta.1

Предварительная Windows x64 версия. Полная desktop-приёмка и принятие пользователем остаются открыты: [ACCEPTANCE](https://github.com/Jetvac/ssh-explorer/blob/v0.2.0-beta.1/ACCEPTANCE.md).

## Изменения

- Устранено подтверждённое падение 0.1.0: выбор профиля вызывал рекурсивное обновление списка через всплывающее событие WPF. Сохранены стек, хеши старой поставки и регрессионный сценарий.
- Компактная форма профиля с inline-ошибками, дополнительными параметрами, проверкой порта/таймаута, защитой от двойного сохранения. Профиль и DPAPI-секрет сохраняются транзакционно; при отказе записи форма сохраняет ввод.
- Вкладки перенесены в caption; сохранены системные кнопки и меню окна. Навигация и панель команд идут над всей файловой областью. Обновлены темы, меню, состояния действий, файловая таблица и мониторинг.
- Исходящий drag использует нативные виртуальные файлы Windows Shell и потоковое SFTP-чтение. Предварительное полное скачивание и повторный жест в этом пути не требуются. Ctrl+C остаётся отдельной командой с подготовкой системного буфера.
- Добавлены Windows CI, фиксированные зависимости, версионированный комплект, `build-info.json` и commit в диагностике.

## Запуск

Скачайте `SSHExplorer-0.2.0-beta.1-win-x64.zip` и `SHA256SUMS.txt`, проверьте SHA-256, распакуйте **всю папку** и запустите `SSHExplorer.exe`. Приложение не требует SDK, Python, отдельно установленного .NET или скачивания WebView2 при первом запуске. Комплект содержит .NET 10.0.14, Fixed WebView2 156.0.4314.58 и локальный xterm.js. Поставка не подписана.

Профиль сохраняется без подключения к серверу. При подключении проверьте публичный host-key сервера по независимому каналу. Сохранение пароля включается отдельно и использует Windows DPAPI текущего пользователя. Клиент не устанавливает компоненты на управляемый сервер.

## Проверено и что остаётся открытым

Подробные результаты: [профили](https://github.com/Jetvac/ssh-explorer/blob/v0.2.0-beta.1/docs/PROFILE_CRASH.md), [UI parity](https://github.com/Jetvac/ssh-explorer/blob/v0.2.0-beta.1/docs/UI_PARITY.md), [CI](https://github.com/Jetvac/ssh-explorer/actions/workflows/windows.yml).

Проверены регрессии ядра, реальные WPF-сценарии профилей, пароль/зашифрованный ключ на изолированном Linux, native COM-получатель и потоковое SFTP. Живо прошли переносы на вкладку другого сервера A→B и B→A с сохранением источника, перемещение в строку папки внутри одной сессии. Малый файл получен настоящим Проводником, контрольные суммы совпали; инструментарий межоконного жеста возвращал ошибку границ окна, поэтому этот результат не закрывает полную матрицу Explorer.

Через отдельный нативный COM-получатель также переданы **2 148 532 224 байта**: source/target SHA-256 совпал; наблюдавшаяся память 63 МиБ у источника и 35 МиБ у получателя. Проверены отмена, закрытие источника, потеря получателя, Skip и изменение пустого файла. Это проверка потокового протокола, не всего GUI/WebView2/Explorer-жеста. [Доказательства](https://github.com/Jetvac/ssh-explorer/blob/v0.2.0-beta.1/docs/DRAG_DROP.md).

Остаются обязательными: полный живой сценарий профилей именно из скачанной поставки, все направления и цели OLE/hover/modifiers, большой и медленный drag с пустым кэшем, отмена/закрытие в настоящем Explorer, полный набор DPI/High Contrast/тем/мониторов и отдельная чистая Windows с offline-терминалом. По просьбе пользователя дальнейшие тесты окон отложены. Зелёный CI не заменяет эти проверки.

Исходники соответствуют неизменяемому тегу [v0.2.0-beta.1](https://github.com/Jetvac/ssh-explorer/tree/v0.2.0-beta.1); точный commit указан в `build-info.json` комплекта. Beta не назначается стабильной latest.
