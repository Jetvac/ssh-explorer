# Контракт интерфейса по референсам

1. Референс 1: верхние вкладки на нейтральной серой поверхности; активная вкладка светлая с округлёнными верхними углами, иконка слева, крестик справа. «+» следует после вкладок. Под ними самостоятельная строка переходов и адреса.
2. Референс 2: компактная командная панель, тонкие разделители, навигационная колонка примерно 240–300 px в зависимости от DPI; строки дерева около 40 px, файловая таблица плотнее (32–36 px). Синий акцент выделения, нейтральное наведение, отдельная рамка клавиатурного фокуса. Панель сведений не заменяет основную таблицу.
3. Референс 3: диспетчер задач с боковой навигацией, поиском, командной панелью и виртуализированной таблицей. CPU и память имеют умеренную синюю тепловую подсветку; значения измеряются, неизвестные не выглядят нулями.

Токены приложения: Segoe UI Variable Text (fallback Segoe UI), основной текст 14 DIP, вспомогательный 12 DIP; высота строки 34 DIP; боковая колонка 244 DIP; тема светлая/тёмная/системная; акцент #0067C0 светлый и #60CDFF тёмный; разделители #E3E3E3/#414141. High Contrast использует системные цвета.

## Выбор UI framework

Базовый WinUI рассмотрен первым. Официальный [каталог WinUI controls](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/) содержит ListView/GridView/ItemsView, но не штатную DataGrid с необходимыми колонками. В WPF доступны DataGrid (виртуализация строк/колонок, изменение порядка и ширины) и зрелый OLE FileDrop API. Это непосредственно снижает два технических риска задания: большие каталоги и Windows Explorer ↔ приложение. Выбран WPF .NET 10 LTS; оболочка, таблицы, дерево и меню остаются нативным Windows desktop UI. Windows App SDK runtime не используется и потому не требуется в поставке. Внешний UI-компонент только WebView2 для локального терминала.

Это техническое отклонение от базового варианта, а не отмена пользовательских требований. Требования поведения, визуальной проверки, доступности и автономной поставки сохраняются.
