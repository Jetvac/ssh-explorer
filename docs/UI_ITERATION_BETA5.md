# Блокнот и системные объекты Windows — beta.5

База — опубликованная beta.4 `1fb919fbf87ff0baa6ecf6fcca242a6b68e614fb`; main/tag/feature и чистое дерево проверены до изменений. Следующий свободный номер — beta.5. Старые теги не меняются.

Работа выполнена по этапам: самостоятельная модель документов/проверяемое SFTP-сохранение; интеграция настоящего Блокнота и списка документов; фоновые системные иконки; исправление пропорций вкладок/текста; целевые проверки и CI-галерея. Выпуск и повторное скачивание связываются через [CI_BETA5](CI_BETA5.md), а не через предположение о совпадении разработческой DLL с релизом.

## Пользовательские действия

«Редактировать в Блокноте» открывает один обычный текст; изображения сохраняют просмотрщик, известные двоичные типы не получают текстовую команду. Отдельный «Просмотр» использует строгое декодирование. Расширение служит подсказкой: неизвестное расширение или отсутствие расширения не запрещает текст, но содержимое проверяется. Предпочитаемый установленный EXE выбирается в параметрах; shell-команд и запуска самого `.sh`/`.bat`/`.ps1` по ассоциации нет.

Рабочая копия подписана безопасным именем документа/сервера и живёт в собственной GUID-папке. Идентичность берётся из профиля, endpoint, пользователя и проверенного host key. Ctrl+S → стабильные локальные байты → immutable snapshot/journal → SFTP temporary → повторная проверка серверного SHA-256 → POSIX rename → перечитывание результата. Изменение длины/mtime не используется вместо hash. Ссылка остаётся ссылкой; её согласованная цель проверяется. Mode, включая executable, uid/gid сохраняются в пределах прав. На SFTP-only аккаунте exec не требуется.

Список документов показывает подготовку/открытую копию/ожидание/отправку/подтверждение/конфликт/ошибку/паузу/неизвестный результат. Есть открытие редактора, сверка, отправка/повтор, экспорт, серверная копия рядом, явное подключение внешнего Save As и завершение. Известные pending-изменения учитываются перед закрытием вкладки; редактор не завершается. После старта черновики приостановлены до обычного подключения и явного возобновления. [Подробный контракт и границы](REMOTE_EDIT.md).

## Иконки и геометрия

В таблице, дереве и всех плитках работает `ShellFileIcon`: `SHGetFileInfoW(USEFILEATTRIBUTES)` по типу и `SHGetImageList` дают ресурсы установленной Windows 16/32/48/256 px. Фоновый STA, общий bounded cache по типу/размеру/окружению, frozen bitmap и освобождение HICON/COM не блокируют UI. В моделях 10 000 файлов не запускают 10 000 Shell-запросов. Размер пересчитывается при DPI; тема/ассоциации инвалидируют cache. Неизвестные и special files имеют нейтральный fallback, у ссылки есть отдельный overlay. Windows DLL/шрифты и извлечённые ресурсы не распространяются.

Командные глифы сохраняют Segoe Fluent Icons и семантический каталог `Ui`; роли размеров и восемь глифов текущего вида выделены в `CommandGlyphs`. Маленький bitmap не растягивается для Huge. Системные ассоциации на Windows Server CI и пользовательской Windows могут давать разные рисунки — это свойство подхода.

`SessionHeaderPanel` размещает «+» сразу за фактической полосой. При двух вкладках зоны стрелок collapsed; при переполнении обе зоны стабильны и крайние направления disabled. Tab reorder и file payload не объединены; native caption сохраняет свою область. «Просмотреть» показывает активный режим. Имена плиток ограничены двумя полными строками с ellipsis/полным tooltip, высота учитывает увеличенный текст. Смена размера текста не пересоздаёт документную модель/редактор имени.

Поверхность документов использует явную тематическую подложку. Её снимок не теряет фон окна за прозрачным root. При узком окне и увеличенном тексте полный статус прокручивается, сохраняя целую строку таблицы. Во время отправки виден прогресс байтов неизменяемой версии и доступна отмена. Это проверяется реальными measured bounds, а не наличием setters.

## Референс и ограничения приёмки

Сопоставление — Windows Explorer → точная опубликованная beta.4 → beta.5. До отзыва Computer Use осмотрен Explorer на Windows build26200.9711/25H2, Light, стандартное Details-представление собственных тестовых файлов. Размер bounded кадра, сообщённый инструментом, 1066×681; DPI/системный масштаб текста отдельно не измерены. Ранее предоставленные пользователем Explorer/Task Manager также имеют неизвестный DPI. Поэтому сравниваются структура, роли и ресурсные иконки, без pixel-perfect оценки системных DIP. Локальный исходный кадр Windows не публикуется с пользовательской боковой панелью; [его метаданные](test-results/beta5-windows-reference.json) фиксируют источник/границы. CI before/after отдельно проверяет одинаковые actual client DIP/DPI/font/culture пяти сцен.

04.11.2026 пользователь разрешил Computer Use, затем запретил дальнейшее использование. Живой тест настоящего Notepad11.2607.14.0 выполнен в разрешённой части и относится к указанной development DLL; после запрета — только код, headless и Windows Actions, без новых host HWND/ввода. [Точные результаты](CI_BETA5.md). Визуальную приёмку выполняет пользователь. Старый парольный crash не диагностирован; новый harness-тест не объявляется доказательством его причины.
