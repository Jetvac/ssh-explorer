# Целевая композиция beta.3

Baseline: `v0.2.0-beta.2`, `e8424e548e89b8406444d3122157542597c3c33f`. Пользователь сообщил, что дошёл до рабочего экрана. Причина прежнего парольного crash по-прежнему не установлена; диагностика и регрессии сохраняются. Интерфейс пользователь ещё не принял.

## Одна оболочка

Верхние вкладки — только «Главная» и именованные серверные сессии. Их явные стили не применяются к внутренним страницам. WindowChrome, системные кнопки, resize, Snap и native keyboard behavior сохраняются.

Слева закреплены Терминал, Диспетчер задач с контекстными подпунктами «Процессы» / «Производительность», Файлы и домашняя папка. Дерево занимает оставшуюся высоту и прокручивается самостоятельно. Открытая страница обозначена нейтральной подложкой и акцентным боковым маркером. Запомненная папка при открытом мониторинге имеет вторичный маркер. Keyboard focus и drop target независимы от этих состояний. Переход страницы сохраняет сами представления, файловую историю, дерево и положение прокрутки.

## Процессы

Одна верхняя область содержит название страницы, поиск и команды. При узкой рабочей области поиск получает отдельную строку, второстепенные действия переходят в overflow. Непосредственно ниже — таблица; CPU/Memory summary находится только в шапках соответствующих колонок. Внизу — одна компактная строка состояния и действие «Сведения о данных». Технические пояснения не занимают постоянную высоту.

ProcessTableStyle и FileTableStyle имеют независимые роли плотности. Минимальная высота строки процессов — 32 DIP с автоматическим ростом содержимого, а не фиксированным обрезанием увеличенного текста. MetricCell растягивается по обеим осям, не наследует padding обычной ячейки; цвет заполняет площадь ячейки, число выровнено вправо. Неизвестное значение — тире с доступной причиной, без цветного нуля. Selection/focus остаются читаемыми поверх heatmap; High Contrast использует системные состояния.

## Данные и производительность

Первоначальный сбор, новая identity процесса, отсутствие источника/прав, сброс счётчиков, пауза и устаревшие данные — разные состояния. Независимые доступные метрики сохраняются. Подробности доступны из status и через tooltips/automation. Завершение процесса доступно только по общей с backend политике; сервис повторно проверяет identity/права. Автоматического sudo и демонстрационных сигналов нет.

Графики получают HistoryPoint с timestamp. Горизонтальная ось отражает фактическое время, пропуски и паузы разрывают линию. Отсутствующие измерения не интерполируются. Hidden monitor не опрашивается, запросы не накладываются.

## Связанные экраны

Общие явные роли: SessionTab, Navigation/SubNavigation, FileTable, ProcessTable/MetricCell, HomeTable, TransferTable, CommandBar, StatusBar, DialogSurface/Validation. Сохраняются восемь файловых представлений, адресная строка, breadcrumbs, preview, SSH/SFTP, терминал и native drag/drop. Обновления не пересоздают все строки. UiMotion не задерживает команды и не анимирует WebView2/HWND.

## Доказательства и границы

Пользователь запретил Computer Use для этой итерации. На его рабочем столе окна не запускаются. Разрешены кодовые/headless проверки и изолированные Windows CI-сценарии, включая реальные WPF layout/render снимки обезличенного стенда. CI-render — снимок приложения, но не ручное управление и не пользовательская приёмка. Видео, физический auth input, полный Explorer gesture, реальные DPI/HC/multi-monitor и чистая Windows остаются отдельными строками.

Направление задают приложенные референсы Explorer и Task Manager. Последний пользовательский снимок приложения в новом сообщении отсутствует; доступный before — исторический live/CI кадр beta.2 `ab01976`, не выдаваемый за новый пользовательский снимок. Масштаб и DPI референсов неизвестны; DIP — проектные значения, не измеренный норматив Explorer.
