# План 0.6 — история метрик

Направление задано пользователем 06.11.2026: запись метрик — и системных (то, что уже показывают «Сервер» и «Диспетчер задач»), и метрик приложений (свои команды, nginx, PostgreSQL и т. п.). Плюс то, что осталось от 0.5. Принят пользователем целиком (06.11.2026). Каждый пункт проверяется в CI: Linux — настоящий SSH-сервер в Docker на Linux-раннере, Windows — OpenSSH Server на Windows-раннере, окна — UI-проверками.

## 1. Хранилище

- Свой формат вместо SQLite: файл на сервер и день (`%LOCALAPPDATA%\SSHExplorer\metrics\<id сервера>\2026-11-06.bin`), записи фиксированного размера, дописываются в конец. Нет нативных библиотек, папку программы по-прежнему достаточно распаковать.
- Свёртка в 5-минутные и часовые точки (среднее, минимум, максимум) идёт в фоне; старые файлы удаляются по сроку. Повреждённый хвост файла (выключение посреди записи) отбрасывается, остальное читается.
- Удаление профиля предлагает удалить и его историю. Пароли и вывод команд в историю не попадают — только числа.

## 2–3. Запись

- Во время открытой вкладки замер идёт по её подключению — один короткий запрос в минуту, отдельного подключения нет.
- Фоновая запись — флажок «Записывать историю» в профиле или папке. Подключение использует сохранённые учётные данные и проверку ключа, как обычное; без сохранённого пароля или ключа фоновая запись недоступна (пароль не спрашивается из фона). Через промежуточный сервер — тоже.
- Пропуск (сервер недоступен, компьютер спал) записывается как пропуск, не как ноль; сама недоступность — событие на графике.

## 4–6. Просмотр

- «История» — раздел в боковой панели сервера и отдельное окно для сравнения. Графики переиспользуют `MetricGraph` (без сглаживания и выдуманных значений), дополнены линиями мин/макс для свёрнутых точек.
- События — значки над графиком с подсказкой; свою отметку («обновил nginx») можно поставить вручную.

## 7. Свои метрики

- Задаются на сервере или на папке (наследуются, как в 0.5). Команда выполняется с правами пользователя SSH, без sudo; перед первым запуском показывается целиком. Вывод разбирается строго: число или строки `имя=значение`; всё остальное — ошибка метрики с текстом, а не ноль.
- Шаблоны подставляют команду и единицу; на Windows — варианты на PowerShell.

## 8. Оповещения

- Правила задаются на графике («оповещать, если…») или в «Настройках»; срабатывают и для фоновых серверов. Прогноз заполнения диска — по линейному тренду за 7 дней, показывается только при достаточной истории.

## 10. Экспорт

- CSV с выбранными метриками и шагом. Точка Prometheus слушает только 127.0.0.1, порт задаётся, отдаёт последние значения серверов с записью; ни адреса, ни имена пользователей в метки не попадают, только имя профиля.

## Вне 0.6

Запись сеансов терминала, синхронизация профилей между компьютерами, отправка в InfluxDB/Graphite — после 0.6, если понадобятся.
