# Замечания к beta.5 → изменения beta.6

База — опубликованная v0.2.0-beta.5 `03cf1479ab4aadd63389b57ffe8182313447b868`. Ветка `claude/beta6-ui-rework`. Работа велась в облачном Linux-контейнере без Windows. Проверки:

- C#: компиляция Roslyn с WPF reference assemblies, без XAML-компилятора;
- 78 Core/Monitoring/Server-проверок в Linux, включая реальный `/proc`;
- Rust: сборка ядра и прогон тестов.

Push в GitHub из этой сессии отклоняется прокси, поэтому **ни один Windows CI для beta.6 не запускался**. Всё, что требует WPF-окна, отмечено «не проверено». Computer Use не использовался: его отзыв в beta.5 по-прежнему действует.

## Что нужно для закрытия «не проверено»

1. Добавить репозиторий в источники сессии и выполнить push. После этого запустятся `windows.yml` (включая `--beta6-ui`, измерение поставки и иконку EXE), `linux-core.yml` и `rust-prototype.yml`.
2. Исправить ошибки CI. XAML и UI-тесты в этой среде не компилировались и не запускались.
3. Пройти ручную матрицу beta.5 из [ACCEPTANCE.md](../ACCEPTANCE.md) с добавлениями beta.6:
   - вкладки: открытие сервера с одной «Главной»;
   - путь: щелчок по свободной части поля;
   - caption: Snap Layouts на Maximize, неактивное окно, High Contrast;
   - графики при медленном сервере;
   - сортировка всех таблиц;
   - панель «Сервер» — только на одноразовой тестовой VM.
