# Замечания к beta.5 → изменения beta.6

База — опубликованная v0.2.0-beta.5 `03cf1479ab4aadd63389b57ffe8182313447b868`. Ветка `claude/beta6-ui-rework`. Работа велась в облачном Linux-контейнере без Windows. Проверки:

- C#: компиляция Roslyn с WPF reference assemblies, без XAML-компилятора;
- 78 Core/Monitoring/Server-проверок в Linux, включая реальный `/proc`;
- Rust: сборка ядра и прогон тестов.

Push в GitHub из той сессии отклонялся прокси, поэтому Windows CI тогда не запускался; результаты последующих прогонов и исправления — в разделе «Windows CI» ниже. Всё, что требует WPF-окна, отмечено «не проверено». Computer Use не использовался: его отзыв в beta.5 по-прежнему действует.

## Windows CI (04.11.2026)

Ветка отправлена в GitHub; первые прогоны `windows.yml` для `b31f802` и `bee4e27` падали. Исправлено по шагам, каждый раз с локальной сборкой (SDK 10.0.403, 0 предупреждений) и headless-режимами на Windows; оконные проверки — только в CI:

| Проявление в CI | Причина | Исправление |
|---|---|---|
| `--connection-only`: «unchanged transfer refresh … property churn» | `TransferRow.Refresh` безусловно поднимал `PropertyChanged` производных свойств | Уведомления только при реальном изменении, включая типизированные ключи сортировки (`6045139`) |
| Нет «Все вкладки», «Документы», «Передачи», «Параметры» и кнопок окна; `AllTabsButton` не найден | `TrailingHost` в шаблоне вкладок использовал `RelativeSource`-привязку, которая не присоединялась: строка заголовка была пустой справа (виден на снимке CI) | `TemplateBinding` + headless-проверка в `--resources-only` (`ed0490f`) |
| На кнопке вида текст `icon:view-details` | Код брал «первый TextBlock» кнопки — после перехода на векторные значки это подпись | Заменяется слот значка (`ed0490f`, тест — `b7bd659`) |
| «the selected tab is revealed inside the viewport during overflow» | Прокрутка к `Header` (без отступов вкладки) до обновления extent | `BringIntoView` всей вкладки после `UpdateLayout` и повтор при изменении extent/viewport (`ed0490f`) |
| `VectorIcon.OnRender`: «Не удается зафиксировать Freezable» в меню | `Pen.Freeze()` с анимируемой/привязанной кистью | Заморозка только при `CanFreeze` (`ed0490f`) |
| `Test-PortableStartup.ps1`: ParserError | Незакрытая строка `MemoryScope` | `f16b658` |
| `Beta6Tests`: AmbiguousMatch `Render` | Перегрузки `ServerPanelView.Render` | Явная сигнатура `Render(ServerInfo)` (`b7bd659`) |
| `Verify-Portable.ps1`: «Unknown WebView2 packaging mode: 156.0.4314.58» на эталоне beta.4 | До beta.6 `build-info.json` хранил только версию Fixed runtime | Старый формат принимается как fixed (`05982e9`) |

Итог: `05982e9` — Windows build and regression **success** (включая `--beta6-ui`, состав поставки, иконку EXE, запуск и закрытие portable EXE), Linux core **success**. Отчёты и снимки — артефакт `Windows-regression-report-05982e95…` прогона 41842608861.

## Что остаётся для закрытия

Зелёный CI подтверждает собранные проверки и снимки, но не визуальную приёмку. Остаётся ручная матрица beta.5 из [ACCEPTANCE.md](../ACCEPTANCE.md) с добавлениями beta.6:

- вкладки: открытие сервера с одной «Главной»;
- путь: щелчок по свободной части поля;
- caption: Snap Layouts на Maximize, неактивное окно, High Contrast;
- графики при медленном сервере;
- сортировка всех таблиц;
- панель «Сервер» — только на одноразовой тестовой VM.
