# История изменений

## 0.2.0-beta.3 — 2026-11-03

- Процессы/Производительность перенесены в левую навигацию. Убраны внутренние window tabs, duplicate summary и постоянный технический footer. Поиск/команды адаптируются к ширине, дополнительные колонки выбираются отдельно.
- Основные разделы закреплены, дерево и закреплённые папки прокручиваются отдельно. Открытая страница, запомненная папка, focus и drop target имеют разные состояния. Контекст файлов и мониторинга сохраняется.
- Полноразмерная метрическая ячейка и числовая сортировка; неизвестные величины — тире с доступной причиной. Единые явные роли серверных вкладок, разных таблиц, команд, статусов и диалогов.
- Различены initial/new-process/unavailable/reset/stale состояния, независимые показатели сохраняются при отсутствии uptime. UI/backend используют общую предварительную политику сигналов; повторная серверная проверка сохранена.
- Графики получают timestamp, отражают фактические интервалы и разрывы после паузы/ошибки/долгого запроса; таблица сохраняет identity строк и выбор.
- Пользователь сообщил об успешном запуске beta.2 до рабочего экрана. Причина прежнего crash не установлена; auth/diagnostic regression сохранена. Computer Use на этой итерации не выполняется; полное визуальное принятие остаётся за пользователем.

## 0.2.0-beta.2 — 2026-11-03, открытый P0

Повторный пользовательский crash актуальной поставки не воспроизведён и остаётся открытым. Последние доступные Windows crash events относятся к 0.1.0; это не доказывает исправность beta.1. Новое [расследование](docs/PROFILE_CRASH.md) отделено от старой рекурсии SelectionChanged.

- «Сохранить и подключиться» передаёт точный пароль в памяти; opt-in DPAPI обновляется после успешного подключения. Недоступный секрет предлагает повторный ввод, прежняя корректная копия защищена от неудачной/устаревшей попытки.
- Operation IDs, cancellation/timeout, защита повторных Connect, owner-bound Trust/Credentials/Interactive, сериализация дополнительных MFA-запросов. Раннее закрытие vendor SSH transport и отмена callback получили сетевые регрессии; OTP не заполняется сохранённым паролем.
- Разделены transport/auth/exec/SFTP, построение UI, первая папка и терминал. Terminal/monitor создаются при открытии; ошибка папки предлагает Home/root. Unknown Dispatcher failures не подавляются безусловно, безопасные fatal/exit записи сбрасываются синхронно.
- Явный шаблон DataGridCell убирает внутренние рамки; общие row selection/focus/drop состояния. Status message не сдвигает таблицу, дерево получает полноширинную строку и заполненные иконки, flyout привязан к источнику, glyphs заданы явно.
- Общий [motion policy](docs/MOTION_SPEC.md): hover-подложка, flyout, рабочая поверхность; interruption заменяет clocks, disabled/HC устанавливают final state. Команды не ждут анимацию, HWND терминала не перемещается.
- Мониторинг и передачи обновляют существующие строки без полного сброса коллекции. Drag/hover cleanup согласован с Esc, закрытием вкладки и завершением операции. Native virtual files протокол сохранён.
- Headless, real-network и CI STA проверки обычных Add/Trust/Connect с новым тестовым процессом для saved-secret reuse. Это не физический ввод или запуск опубликованного EXE. Live UI, DPI/HC/Explorer/video и clean Windows остаются открыты: [приёмка](ACCEPTANCE.md).
- Исправлена изоляция тестового WPF Application: queued OnStartup больше не открывает лишний desktop и обычный store в component runner. Старые утверждения профильных прогонов «без окон» отозваны; новый isolated повтор — 94 assertions с контролем нулевых startup/visible/HWND. Startup настоящего packaged EXE проверяется отдельным CI-only процессом.
- Версионная portable-папка beta.2, clean source commit, включённые .NET/WebView2 и SHA-256. Python/Paramiko нужны только стенду разработки/CI, не пользователю приложения.

## 0.2.0-beta.1 — 2026-11-03

Предварительная версия. Пользовательская приёмка **не закрыта**; обязательные открытые пункты перечислены в [ACCEPTANCE.md](ACCEPTANCE.md). Текущее сопоставление с референсами и статус реальных снимков — [UI_PARITY.md](docs/UI_PARITY.md). Выпуск и его загрузки публикуются на [GitHub Releases](https://github.com/Jetvac/ssh-explorer/releases).

### Исправления профилей

- Воспроизведён fatal StackOverflow 0.1.0: `DataGrid.SelectionChanged` всплывал до обработчика серверных вкладок и рекурсивно перестраивал Главную. Обработчик теперь принимает только событие самого TabControl; обновление Главной защищено от повторного входа.
- Добавление и изменение используют одну форму с явным сохранением, PasswordBox для пароля/passphrase, проверкой полей и дополнительными настройками. Профиль можно сохранить без доступного сервера.
- Запись профиля и DPAPI-секрета согласована. При ошибке записи форма сохраняет поля, не публикует частичный профиль и остаётся пригодной для повторного сохранения; отмена не меняет хранилище. MainWindow не сохраняет профиль повторно.
- Реальный STA-прогон: 65 проверок профилей, сохранения и modal/MainWindow сценариев. [Лог](docs/test-results/profiles-v02-sta.log), [доказательство падения baseline](docs/test-results/profile-crash-baseline.json).

### Интерфейс Windows 11

- Вкладки перенесены в верхнюю область WindowChrome; сохранение нативных caption-кнопок, Snap, resize и системного меню проверяется отдельными живыми сценариями.
- Адрес/поиск и компактная командная панель теперь проходят через всю ширину файлового раздела; дерево начинается ниже них. Убраны крупный дублирующий заголовок Главной и лишняя полоса состояния над содержимым.
- Общие Fluent-иконки, Light/Dark/High Contrast ресурсы, системный акцент, hover/selected/focus/disabled состояния. Действия выбора выключаются без подходящего объекта.
- Исправлены обрезка длинных имён и исходная видимость дополнительных колонок; правый клик сохраняет выделенную группу. Область просмотра адаптируется к узкому окну. Все восемь реальных представлений сохранены.
- Диспетчер задач получил числовые заголовки CPU/памяти, поиск с подсказкой, доступность завершения процесса по выбору и графики с последним замером у правого края.
- Добавлены проверки загрузки реальных Light/Dark/System/HC ресурсов. Они проверяют стили и не заменяют осмотр окна при разных DPI и темах.

### Перетаскивание и буфер обмена

- Для сервер → Windows добавлен нативный OLE-источник виртуальных файлов `FILEDESCRIPTORW`/`FILECONTENTS`, потоковый `IStream` и `IDataObjectAsyncCapability`. Экспорт больше не требует предварительного полного скачивания и повторного жеста. Данные читаются с ограниченным буфером через выделенный MTA-host.
- Источник копирования Windows → сервер — реальные Windows файловые объекты. Межсерверное копирование, перемещение в пределах сессии, Ctrl/Shift, запрет self/descendant и недоступные назначения проверяются общими правилами назначения.
- Подсветка цели, hover переключения вкладки, очистка drop-состояния и обновление исходного вида после перемещения согласованы. Payload вкладок и файлов использует непрозрачные raw-токены со слабыми ссылками, без сериализации CLR-объектов.
- `Ctrl+C` по-прежнему готовит локальные `CF_HDROP` в `TransferCache`; это отдельный механизм. Защита sequence-number предотвращает замену более нового содержимого системного буфера после долгого скачивания.
- Живо проверены небольшие файлы между вкладками A↔B и перемещение в строку папки внутри сессии. Полная Explorer/large/cancel матрица и сохранность источника требуют отдельной приёмки; COM ABI-тест не выдаётся за доказательство живого drag/drop.

### Поставка и воспроизводимость

- Версия `0.2.0-beta.1` закреплена в общих build properties. Portable ZIP, папка и source ZIP имеют версию в имени; существующая папка выпуска не перезаписывается.
- `Build-Release.ps1 -RequireClean` собирает чистый Git checkout, запускает регрессии и создаёт `build-info.json` с commit и версиями runtime. Сборка изменённого checkout помечается `.dirty`.
- Добавлены исходный ZIP из закоммиченных файлов, SHA-256-манифесты и Windows CI с закреплёнными Actions. CI публикует артефакты проверки; публикация GitHub Release — отдельный шаг.
- Portable-поставка содержит self-contained .NET и закреплённый WebView2 Fixed Runtime. Подпись издателя и отдельная чистая Windows остаются открытыми пунктами.

## 0.1.0 — исходная сборка

Реализованы SSH/SFTP, host-key verification, DPAPI opt-in, независимые вкладки, файловые операции и очередь, настоящий PTY/xterm.js, PNG/JPEG и монитор `/proc`. Backend и Linux-сценарии записаны в [TEST_REPORT.md](docs/TEST_REPORT.md).

Эта сборка не была принята пользователем: обнаружено падение добавления профиля, визуальные отличия от Windows 11 и исходящий drag/drop через предварительный кэш. Она служит baseline для 0.2; старые screenshots и тесты не закрывают приёмку новой версии.
